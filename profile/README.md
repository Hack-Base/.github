## 🚀 What is HackBase?

HackBase is a community-driven GitHub organization focused on collaborative learning through open source. From beginner-friendly tasks to impactful projects — all are welcome!

**You can:**
- Collaborate on real-world projects
- Learn by doing with support from the community
- Showcase your contributions
- Build your public developer portfolio

---

## 🛠️ Getting Started

1. **Join the Organization**  
   Raise an issue [here](https://github.com/HackBaseOrg/support/issues/new?template=invitation.yml&title=Please+invite+me+to+HackBase) for an invite.

2. **Join Our Discord**  
   Chat, learn, and collaborate with others on [Discord](https://discord.gg/hackbase).

3. **Make Your First Contribution**  
   Try our [first-contribution-practice repo](https://github.com/HackBaseOrg/first-contribution-practice) to get started.

4. **Explore Projects**  
   Browse active repositories on the [HackBaseOrg GitHub](https://github.com/HackBaseOrg).
